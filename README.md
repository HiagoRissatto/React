# Estudos de React + TypeScript

Projeto desenvolvido com o objetivo de praticar e reforçar meus conhecimentos em **React**, **TypeScript** e **Bootstrap**.

O projeto será atualizado conforme avanço nos estudos, adicionando novos componentes e conceitos do React.

## Objetivo

O principal objetivo deste projeto é colocar em prática os conceitos estudados durante meu aprendizado de React, desenvolvendo pequenos componentes e exercícios.

## Tecnologias utilizadas

* React
* TypeScript
* Bootstrap
* Vite

## Conceitos praticados

Até o momento, o projeto aborda:

* Componentização
* Componentes pai e filho
* Props
* Tipagem de Props com TypeScript
* Desestruturação de Props
* Reutilização de componentes
* Tipos `string`, `number` e `boolean`
* Renderização condicional
* Operador ternário
* Estilização utilizando Bootstrap
* Flexbox com Bootstrap
* Responsividade básica

## Componentes

### Usuario

Componente responsável por exibir informações de um usuário através de Props.

Informações utilizadas:

* Nome
* Idade
* Profissão

### Produto

Componente criado para praticar Props e renderização condicional.

Informações utilizadas:

* Nome do produto
* Valor
* Disponibilidade

A disponibilidade é representada por um valor `boolean`, permitindo exibir diferentes informações dependendo do estado do produto.
